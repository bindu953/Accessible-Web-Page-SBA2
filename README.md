# Accessible Design Co. Website

## About the Project

This is a simple website I created for my HTML and CSS Skills-Based Assessment (SBA2).

The goal of this project is to practice building a responsive and accessible website using HTML and CSS. I also learned how to organize webpage content and make it easy for everyone to use.

## Implemented using

- HTML
- CSS
- Flexbox
- CSS Grid
- Visual Studio Code
- Git and GitHub

## Website Features

My website includes the following sections:

- **Header:** Placeholder Company logo and navigation links.
- **Hero Section:** Welcome message, background image, and Contact Us button.
- **About Us:** Information about the company.
- **Services:** Three service cards displayed using CSS Grid.
- **Contact Form:** Fields for name, email, subject, and message.
- **Footer:** Company information, contact details, and social media links.

## Responsive Design

I used Flexbox for the navigation bar and footer and CSS Grid for the services section.

I also used media queries to adjust the layout for different screen sizes, including desktops, tablets, and mobile phones.

## Accessibility

I added accessibility features to make the website easier to use.

- Used semantic HTML tags like `header`, `main`, `section`, `article`, and `footer`.
- Added alternative text for images.
- Used labels for form fields.
- Added ARIA attributes where needed.
- Used readable fonts and contrasting colors.

## How to Run the Project

1. Download or clone this repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click and select **Open with Live Server**, or open the file directly in a browser.

## What I Learned

Through this project, I learned how to create a webpage using semantic HTML and style it using CSS. I practiced using Flexbox, CSS Grid, and media queries to make the website responsive.

I also learned why accessibility is important and how small changes, such as adding image descriptions, form labels can make websites easier to use.

## Conclusion

This project helped me improve my HTML and CSS skills and gave me a better understanding of responsive and accessible web design.
