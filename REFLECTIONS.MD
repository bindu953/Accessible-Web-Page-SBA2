
## Reflection Questions

### 1. What accessibility challenges did you face, and how did you address them?

One of the challenges I faced was understanding how to make my website accessible to everyone. At first, I was not very familiar with ARIA attributes and how they work. I learned how to add proper labels to form fields and alt text to images. I also made sure the text colors were easy to read against the background.

### 2. How did you ensure that your design was responsive and accessible to all users?

I used Flexbox to arrange the navigation bar and footer and CSS Grid to display the services. I added media queries so the layout changes based on the screen size. For example, the service cards appear side by side on larger screens and stack vertically on mobile screens. I also tried to keep the website simple and easy to navigate.

### 3. What tools or resources did you find most helpful during this project?

I mostly used Visual Studio Code to write my HTML and CSS. Live Server was really helpful because I could see how my website looked whenever I made changes. I also used Chrome Inspect to check my CSS and understand why some styles were not working. My Per Scholas course and instructors instruction material helped me understand the concepts better, especially Flexbox, Grid, and accessibility.
